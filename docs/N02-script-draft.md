## 場景 1　舊館外・深夜（承接 N01 結尾）
（安全門在身後關上。街燈下，有人靠著機車，等了很久的樣子。）

- 達克：……終於出來了。你知道我在這裡等了多久嗎？
- {主角}：（左右看了看）……你在跟我說話？
- 達克：這條街上還有別人嗎？
- {主角}：抱歉，你是……？
- 達克：（冷笑）好啊，又來這套。上次是假裝沒看到我，這次乾脆不認識了？
- {主角}：我是真的不知道你是誰。
- 達克：達克・利姆。同一個指導教授、同一間研究室，被你搶走兩次研究經費的那個人。想起來了嗎？
- {主角}：……沒有。
- 達克：（盯著主角看了兩秒）算了。教授叫我來接你，其他的我不想知道。上車。
- {主角}：教授叫你來的？
- 達克：不然你以為我會自己想來？
- {主角}（心裡）：竟然有人在等我。而且……這個人好像很討厭我。

（系統）前往：學校・教授研究室

## 場景 2　學校・教授研究室
（深夜的研究室，只開了一盞桌燈。教授站在窗邊，聽到腳步聲轉過身。）

- 教授：你出來了。很好。
- {主角}：教授……你在電話裡說，出來以後再說。
- 教授：嗯。先坐。（看向達克）達克，謝謝你跑這一趟。
- 達克：您開口，我能不來嗎。
- 教授：（轉向主角）你還記得他嗎？
- {主角}：……不記得。
- 達克：他從見面就一直這樣。我說教授，這傢伙是不是又在——
- 教授：他沒有在演。（停頓）{主角}，你還記得多少？
- {主角}：今晚以前的事……很模糊。舊館裡，還少了七分鐘。
- 達克：（皺眉，第一次沒有接話）
- 教授：達克，我想拜託你一件事。帶他回住處。熟悉的地方，也許能讓他想起一些東西。
- 達克：……為什麼是我？
- 教授：因為你是最了解他的人。就算你們吵了三年。
- 達克：（別過頭）我只是記得他所有壞習慣。
- 教授：那就夠了。（轉向主角）還有，你之前收集的那些歷史文件，回去整理一下。你失憶前……已經快摸到某些東西了。
- {主角}：什麼東西？
- 教授：等你自己找到，我再告訴你我知道的部分。

### 謎題 1　研究室的學生置物櫃（拿回住處鑰匙）
- 主角的置物櫃上了密碼鎖，主角當然不記得密碼。
- 線索：主角在研究室的座位（桌上的東西、貼紙、便條），推出自己設密碼的習慣。
- 達克的嘲諷提示（第一次卡住時）：
  - 達克：你這個人，連密碼都要跟研究扯上關係。看看你的桌子。
- 打開後：住處鑰匙、一本封面磨損的筆記本（之後用）。
- {主角}：這是我的筆記？
- 達克：你走到哪帶到哪。上次我碰一下，你差點跟我翻臉。

（系統）前往：{主角}的住處

## 場景 3　{主角}的住處・門口
（老公寓的三樓。走廊的燈壞了一半。）

- 達克：到了。
- {主角}：你怎麼知道我住這裡？
- 達克：教授的研究會在這裡辦過一次。你煮的咖啡難喝到我記到現在。
- {主角}（看著門）：鑰匙能開外面的鐵門，可是裡面這道……是密碼鎖。
- 達克：（嘆氣）你連自己家都進不去？

### 謎題 2　住處門口的密碼鎖
- 線索：門口的生活痕跡（信箱裡的帳單、門邊的鞋櫃、門牌、筆記本第一頁）。
- 達克的嘲諷提示：
  - 達克：你這種人，會把重要的數字寫在自己天天看得到、別人卻看不懂的地方。

（門開了。屋裡很亂，桌上、地上、牆上，到處都是文件。）

- 達克：……你是被搶了，還是本來就住成這樣？
- {主角}：我也很想知道。

## 場景 4　{主角}的房間
- {主角}：這些……都是我收集的？
- 達克：你從大一就在找這些東西。問你在找什麼，你只會說「等我確定再說」。
- {主角}：我確定了嗎？
- 達克：看起來是快了。不然你不會半夜一個人跑去那間舊館。

### 謎題 3　整理文件（錯一次亮一格，3 格失敗）
- 文件散成一地。牆上貼著主角自己訂的分類規則（只寫了一半），筆記本裡有另一半。
- 玩家要把文件放回正確的資料夾／年代。
- 📄 文件 A、B、C、D：用途＝分類練習；內容待討論（建議是看起來普通的歷史資料，玩家要找出共同點才能分類）。
- 分錯時：
  - 第 1 次　達克：……那份不屬於那裡。你以前分得比這個快。
  - 第 2 次　達克：（敲桌面）{主角}，你真的看得懂自己的東西嗎？

### 謎題 4　讀懂文件（錯也算格）
- 分好類以後，主角發現其中幾份文件指向同一件事。
- 玩家要把線索連起來，回答「我之前在查什麼」（選擇題，不出現組織名稱）。
- 📄 文件 E、F：用途＝串起線索的關鍵；內容待討論。
- 答對後：
  - {主角}：這些年代、這些地點……都有同一群人經手。
  - 達克：同一群人？
  - {主角}：名字每次都不一樣。可是做事的方法一模一樣。
  - 達克：（看著文件，安靜了很久）

### 失敗（3 格亮滿，A 案）
- 達克：（把文件一疊疊收起來）夠了。
- {主角}：等一下，我快——
- 達克：你連自己的東西都看不懂？今晚就到這裡。我明天還有課。
- （門關上。房間又變回一團亂。）
- 失敗畫面：「達克失去了耐心」→ 重新挑戰（略過前面已看過的劇情）
