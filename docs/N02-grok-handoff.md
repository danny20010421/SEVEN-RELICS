## 一、劇情摘要
1. **舊館外・深夜**：主角離開舊文獻館，發現有人在等他——達克・利姆，教授的學生、主角研究室的同學。主角完全不記得他，一臉懵；達克不知道主角失憶，只說教授要他來接人。
2. **教授研究室**：教授確認主角失憶，拜託達克帶主角回住處，看熟悉的地方能不能讓他想起什麼。教授要主角整理自己之前收集的歷史文件——他失憶前已經快查到某些東西。主角打開自己的置物櫃，拿到住處鑰匙、筆記本、研究室出入證。
3. **公寓門口**：主角用筆記本和出入證推出自己家門的密碼。
4. **主角房間**：房間堆滿文件。主角依自己訂的規則整理文件，再從文件裡看出「不同年代、不同名字，卻用同樣手法的一群人」。錯 3 次，達克會收走文件離開。
5. **結尾**：筆記本最後一頁寫著「是他。」，和舊館借閱卡同一個筆跡，旁邊的名字被塗掉。達克完成教授交代的事後離開。

### 角色注意事項
- 達克：本節**不描寫個性、不描寫和主角的關係**，只呈現「受教授所託協助」。說話簡短、冷淡。
- 達克是女扮男裝，但**本節完全不揭露、不暗示**，美術請維持立繪的樣子。
- 不出現「姆組織」名稱、標誌或任何可辨識的組織符號。
- 文件的實際內容還在討論，**所有紙張、文件請做空白版**，字由程式寫上。

## 二、美術需求

規格沿用 N01：
- 背景母片 3840×2160，另給 1920×1080 webp；近景母片 2560×1440，另給 1920×1080 webp
- 畫風沿用 N01（昏暗、暖黃燈光、舊紙質感）
- 圖上**不要有任何文字**（門牌數字、按鍵數字除外，見下表）
- 每張背景／近景請附座標 JSON（熱點矩形，母片像素），比照 `docs/N01-doc-geometry.json`
