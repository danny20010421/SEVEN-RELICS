# N02 第一章第二節　劇情大綱（草稿，待確認）

## 角色：達克·利姆（N02-CHAR-015）
- 立繪：`assets/img/N02-CHAR-015.webp`（白西裝長大衣版，先用這張）
- 對外是男生、看起來像不良少年；實際是女扮男裝。**本節不揭露，也不埋暗示。**
- 主角的同學、死對頭，同為教授的學生。智商極高，冷酷、傲嬌，但可靠。
- 在孤兒院長大，為了保護院裡沒被收養的孩子，把自己打扮得很兇。
- 隱藏設定（本節不揭露）：姆組織用上任長老「愛因斯坦」的基因改造出的人造人；之後與主角一起發現「智」的秘寶。

## 本節的核心張力
**沒有人知道主角失憶。** 達克只是接到教授通知來接人。
主角不記得達克是誰，卻得裝作認得這個死對頭，還要瞞過一個智商極高的人。
玩家的樂趣：一邊解謎，一邊別露餡。

⚠ 待確認：教授託達克「帶主角回住處看能不能恢復記憶」，代表教授至少知道或懷疑主角的記憶有問題。
大綱暫定為：**教授心裡有數，但對達克只說「帶他回家整理之前的歷史文件」**，達克不知道真正原因。

## 段落
1. **舊館外**（承接 N01 結尾）
   - 主角走出舊館，有人靠在門邊等他。對方叫得出他的名字，口氣很衝。
   - 主角完全不認得對方，只能順著話接。
   - 玩家選擇：怎麼回應對方（選錯會讓達克起疑，不算失敗，只影響好感／懷疑值）。
2. **學校・教授研究室**
   - 教授當面見到主角，只問「沒事吧」，沒有多說。
   - 教授交代：達克帶你回住處，把你之前整理到一半的歷史文件理一理。
   - 謎題 1：研究室的門禁或櫃子，需要主角「應該知道」的資訊——主角不知道，只能從環境推理，同時不能讓達克看出來。
3. **主角的住處**（本節主場景）
   - 主角站在自己家門口卻不記得密碼；達克在旁邊等，不耐煩。
   - 謎題 2：進門（從門口的生活痕跡推出密碼）。
   - 謎題 3：房間裡散亂的歷史文件，依某種分類規則還原（主角自己訂的規則，要從筆記推出來）。
   - 達克會用嘲諷的方式給提示（他了解主角的習慣，因為是死對頭）。
4. **文件裡的線索（伏筆）**
   - 整理完後，找到一份與 N01 相關的東西（例如：和借閱卡上同樣筆跡的筆記，或指向舊館卷宗的索引），主角明白自己之前在查某件事。
   - 長老身分仍不揭露。
5. **結尾**
   - 達克臨走前丟下一句話，讓玩家感覺他察覺到什麼，但沒說破。
