# N02 第一章第二節　劇情大綱（草稿，待確認）

## 角色：達克·利姆（N02-CHAR-015）
- 立繪：`assets/img/N02-CHAR-015.webp`（白西裝長大衣版，先用這張）
- 對外是男生、看起來像不良少年；實際是女扮男裝。**本節不揭露，也不埋暗示。**
- 主角的同學，同為教授的學生。本節不描寫他的個性與兩人關係，只呈現「受教授所託協助主角」。
- 在孤兒院長大，為了保護院裡沒被收養的孩子，把自己打扮得很兇。
- 隱藏設定（本節不揭露）：姆組織用上任長老「愛因斯坦」的基因改造出的人造人；之後與主角一起發現「智」的秘寶。

## 本節的核心張力
**沒有人知道主角失憶。** 達克只是接到教授通知來接人。
主角**不假裝**：他一臉懵，完全不認得眼前的人，只覺得「竟然有人來接我」。
達克不知道主角失憶，把主角的反應當成故意裝傻、找碴，或又在擺架子——兩人的對話因此雞同鴨講，張力和笑點都從這裡來。
玩家和主角一樣，從達克的話裡一點一點拼出「這個人是誰、我們是什麼關係」。

**教授知道主角失憶。** 在研究室，教授拜託達克帶主角回住處，看能不能幫他恢復記憶。
達克是到研究室才從教授口中得知（來接人時還不知道，所以舊館外那段才會雞同鴨講）。
主角在失憶前已經快摸到姆組織的資料，這次回住處要整理的，就是他自己之前收集的歷史文件。

## 段落
1. **舊館外**（承接 N01 結尾）
   - 主角走出舊館，有人靠在門邊等他。對方叫得出他的名字，口氣很衝。
   - 主角一臉懵：「……你是誰？」「有人來接我？」
   - 達克以為主角在耍他，冷冷回嘴；主角從他的話裡才知道：兩人是同學、是教授的學生，而且關係很差。
2. **學校・教授研究室**
   - 教授當面見到主角，確認他失憶的狀況。
   - 教授拜託達克：帶他回住處，看能不能幫他恢復記憶。達克這時才知道主角失憶，態度微妙地變了一下（嘴上還是很衝）。
   - 教授交代主角：把你之前收集的歷史文件整理一下，你失憶前已經快摸到某些東西了。
   - 謎題 1：研究室的門禁或櫃子，需要主角「應該知道」的資訊——主角不知道，只能從環境推理；達克在旁邊嫌他慢。
3. **主角的住處**（本節主場景）
   - 主角站在自己家門口卻不記得密碼；達克在旁邊等，不耐煩。
   - 謎題 2：進門（從門口的生活痕跡推出密碼）。
   - 謎題 3：房間裡散亂的歷史文件，依某種分類規則還原（主角自己訂的規則，要從筆記推出來）。
   - 謎題 4：讀懂文件——把文件裡的線索連起來，回答「我之前查到了什麼」。
   - 達克會用嘲諷的方式給提示（他了解主角的習慣，因為是死對頭），主角則一臉「原來我是這樣的人？」
4. **文件裡的線索（伏筆）**
   - 整理完後，找到一份與 N01 相關的東西（例如：和借閱卡上同樣筆跡的筆記，或指向舊館卷宗的索引），主角明白自己失憶前已經快查到姆組織。
   - 長老身分仍不揭露。
5. **結尾**
   - 達克臨走前丟下一句話，讓玩家感覺他察覺到什麼，但沒說破。
