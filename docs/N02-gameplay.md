# N02 第一章第二節　玩法與關卡設計（草稿 v1）

劇情見 `docs/N02-script-draft.md`。本文件只寫玩法：場景、熱點、謎題規則、提示、失敗。
⚠ 文件（📄）裡的實際內容待製作人確認；這裡先寫「需要什麼樣的資訊」，括號內是建議，不是定案。

## 一、流程
```
序（舊館外對話）→ A 教授研究室〔謎題 1〕→ B 公寓門口〔謎題 2〕→ C 主角房間〔謎題 3 → 謎題 4〕→ 結尾
```
- 不限時。沒有保安警戒。
- **失敗只發生在房間（謎題 3、4）**：錯 3 次 → 達克收走文件離開（A 案）＝遊戲失敗。
- 重新挑戰：**整節從頭開始**（已看過的劇情可略過）。（已定案）
- 提示：每次提示 1 顆鑽石，三段式：方向 → 具體 → 答案。（已定案）

## 二、場景與熱點

### 序　舊館外（N02-BG-001）
- 純劇情，無熱點。達克立繪出場。

### A　教授研究室（N02-BG-002）
| 熱點 | 作用 |
|---|---|
| 主角的座位 | 打開近景 DETAIL-005（論文草稿、便條、桌曆） |
| 學生置物櫃（主角那格） | 打開近景 DETAIL-006（四位數轉盤鎖） |
| 教授 | 再聽一次交代（劇情重播） |
| 達克 | 簡短回應（不給提示） |
| 門 | 謎題 1 完成前：「還沒拿到鑰匙」；完成後前往 B |

**謎題 1　置物櫃密碼（4 位數）**
- 線索 1（便條）：「密碼：論文的第一個年份。別再忘了。」
- 線索 2（論文草稿封面）：標題含一段年份範圍（例：「〇〇〇〇—〇〇〇〇年間的△△紀錄研究」），取前面那個年份。
- 干擾：桌曆上圈了別的日期。
- 錯誤：轉盤卡住、輕微晃動，不算失敗。
- 完成：取得 🔑 住處鑰匙、📓 主角的筆記本、🪪 研究室出入證（印有第一次登記的日期）。
- 提示三段：看你的桌子 → 便條說的是論文 → 封面上的第一個年份。

### B　公寓門口（N02-BG-003）
| 熱點 | 作用 |
|---|---|
| 鐵門 | 用 🔑 打開（自動） |
| 門牌 | 「37」 |
| 信箱 | 近景 DETAIL-008：帳單信封（收件人是主角，確認是自己家） |
| 鞋櫃 | 只有一雙鞋、一把傘（生活痕跡，無線索） |
| 密碼鎖 | 近景 DETAIL-007（六位數按鍵） |

**謎題 2　家門密碼（6 位數）**
- 線索 1（筆記本第一頁）：「家門：門牌，接上我第一次進研究室的那天（月日）。」
- 線索 2（門牌）：37
- 線索 3（研究室出入證）：首次登記日期 〇〇月〇〇日
- 答案格式：37＋MMDD（例：出入證 09/18 → 370918）
- 錯誤：嗶嗶聲，不算失敗。
- 提示三段：筆記本第一頁 → 門牌和出入證 → 答案。

### C　主角房間（N02-BG-004）
| 熱點 | 作用 |
|---|---|
| 牆上的分類規則（只寫一半） | 讀文件 |
| 地上的文件堆 | 打開近景 DETAIL-009（整理桌，謎題 3） |
| 軟木板 | 謎題 3 完成後開放：近景 DETAIL-010（謎題 4） |
| 書桌 | 筆記本（含分類規則的另一半；結尾翻到最後一頁） |
| 達克 | 靠在門邊（只在答錯時說話） |

**謎題 3　整理文件（錯一次亮一格）**
- 四份文件 📄 A～D，四個資料夾（依年代分）。點文件 → 點資料夾。
- 規則（牆上一半＋筆記本一半）：
  - 牆上：「依年代歸檔，每十年一個資料夾。」
  - 筆記本：「所有年份先換成西元再分。」
- 關卡設計重點：四份文件用**不同的紀年方式**（建議：西元、民國、明治／大正、干支或皇紀等），玩家要換算後才能分對。
- 📄 A～D 內容：⚠ 待討論（建議是看起來彼此無關的普通歷史資料：公文、剪報、帳簿、照片背面說明）。
- 換算對照表放在書架上（可點開），降低難度。

**謎題 4　讀懂文件（錯一次亮一格）**
- 軟木板上釘著 📄 E、F 和整理好的 A～D。
- 步驟 1：選出「指向同一件事」的三份文件（點選三份）。
- 步驟 2：回答「我之前在查什麼？」四選一（沿用 N01 最終推理的兩步介面）。
  - 正解方向：「不同年代、不同名字，卻用同樣手法經手同類物品的一群人」
  - ⚠ 選項文字不能出現組織名稱。
- 📄 E、F 內容：⚠ 待討論（關鍵是「名字不同、手法相同」的共同點要看得出來）。

### 結尾
- 謎題 4 完成 → 筆記本最後一頁（「是他。」＋被塗掉的名字，與 N01 借閱卡同筆跡）→ 達克離開 → 完。

## 六、文件與密碼內容（Claude 暫編 v3，待製作人看過再調整）

方向：世界各地、不同機構的調查報告、歷史事件分析、科學與生物研究紀錄。
共同點——**不同國家、不同年代、不同名字的機構，都以「研究」為名帶走樣本或器物，一律送往「南極研究室」，之後從未公開。**
不出現組織名稱、不出現符號；所有機構名稱都是虛構的。「第七」不再出現在文件裡（七只代表七件秘寶）。
伏筆只做到「很隱晦」：本節不碰姆組織角色（第 3 章）、也不碰「智」的秘寶（第 6 章之後）。

### 謎題 4　讀懂文件（兩題，各四選一）
- 📄 E（舊信紙 DOC-020，無署名、無日期）：
  「各地機構更名一事，已照辦。一律送往南極研究室。不得公開，不得歸還。」
  - 隱藏細節：信紙角落有一個淡淡的浮水印，像一個看不清的外文字母（德文花體風格，但無法辨認）。主角與達克都不提，提示也不會提。
- 📄 F（主角筆記，DOC-011）：
  「北方礦物學會（1908）／東亞古代文明研究所（1937）／？基金會（1955）／熱帶生命科學協會（1978）
  國家不同，名字不同。都說『為了研究』。最後都送到同一個地方。之後都沒有公開。
  南極？為什麼是南極？」
- 第一題：這些文件的共同點是？
  1. 都發生在亞洲
  2. **都以研究為名帶走樣本或器物，送往南極研究室，從未公開** ✓
  3. 都是政府主導的計畫
  4. 都和戰爭有關
- 第二題：我之前在查什麼？
  1. 二十世紀的科學造假事件
  2. **一群在世界各地不斷改名、以研究為名收走樣本與器物的人** ✓
  3. 各國的考古走私網
  4. 南極探險的歷史
- 答錯任一題亮一格（與謎題 3 共用三格）。

### 伏筆說明（本節都不解釋）
- 「南極研究室」：收走的東西去了哪裡，留給後面章節。
- 📄 B 無法辨識的文字、📄 C 古代天文儀器：只是「古老而超出時代的知識」的淡淡印象，不指向任何人或任何秘寶。
- 📄 F 的「？基金會」名字留空。
- 📄 E 的浮水印：為之後「南極研究室」的背景（德國南極探險與相關傳說，故事中以虛構方式呈現）埋線。不出現任何真實人名或納粹符號。
