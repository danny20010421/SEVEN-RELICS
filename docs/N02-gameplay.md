# N02 第一章第二節　玩法與關卡設計（草稿 v1）

劇情見 `docs/N02-script-draft.md`。本文件只寫玩法：場景、熱點、謎題規則、提示、失敗。
⚠ 文件（📄）裡的實際內容待製作人確認；這裡先寫「需要什麼樣的資訊」，括號內是建議，不是定案。

## 一、流程
```
序（舊館外對話）→ A 教授研究室〔謎題 1〕→ B 公寓門口〔謎題 2〕→ C 主角房間〔謎題 3 → 謎題 4〕→ 結尾
```
- 不限時。沒有保安警戒。
- **失敗只發生在房間（謎題 3、4）**：錯 3 次 → 達克收走文件離開（A 案）＝遊戲失敗。
- 重新挑戰：**整節從頭開始**（已看過的劇情可略過）。（已定案）
- 提示：每次提示 1 顆鑽石，三段式：方向 → 具體 → 答案。（已定案）

## 二、場景與熱點

### 序　舊館外（N02-BG-001）
- 純劇情，無熱點。達克立繪出場。

### A　教授研究室（N02-BG-002）
| 熱點 | 作用 |
|---|---|
| 主角的座位 | 打開近景 DETAIL-005（論文草稿、便條、桌曆） |
| 學生置物櫃（主角那格） | 打開近景 DETAIL-006（四位數轉盤鎖） |
| 教授 | 再聽一次交代（劇情重播） |
| 達克 | 簡短回應（不給提示） |
| 門 | 謎題 1 完成前：「還沒拿到鑰匙」；完成後前往 B |

**謎題 1　置物櫃密碼（4 位數）**
- 線索 1（便條）：「密碼：論文的第一個年份。別再忘了。」
- 線索 2（論文草稿封面）：標題含一段年份範圍（例：「〇〇〇〇—〇〇〇〇年間的△△紀錄研究」），取前面那個年份。
- 干擾：桌曆上圈了別的日期。
- 錯誤：轉盤卡住、輕微晃動，不算失敗。
- 完成：取得 🔑 住處鑰匙、📓 主角的筆記本、🪪 研究室出入證（印有第一次登記的日期）。
- 提示三段：看你的桌子 → 便條說的是論文 → 封面上的第一個年份。

### B　公寓門口（N02-BG-003）
| 熱點 | 作用 |
|---|---|
| 鐵門 | 用 🔑 打開（自動） |
| 門牌 | 「37」 |
| 信箱 | 近景 DETAIL-008：帳單信封（收件人是主角，確認是自己家） |
| 鞋櫃 | 只有一雙鞋、一把傘（生活痕跡，無線索） |
| 密碼鎖 | 近景 DETAIL-007（六位數按鍵） |

**謎題 2　家門密碼（6 位數）**
- 線索 1（筆記本第一頁）：「家門：門牌，接上我第一次進研究室的那天（月日）。」
- 線索 2（門牌）：37
- 線索 3（研究室出入證）：首次登記日期 〇〇月〇〇日
- 答案格式：37＋MMDD（例：出入證 09/18 → 370918）
- 錯誤：嗶嗶聲，不算失敗。
- 提示三段：筆記本第一頁 → 門牌和出入證 → 答案。

### C　主角房間（N02-BG-004）
| 熱點 | 作用 |
|---|---|
| 牆上的分類規則（只寫一半） | 讀文件 |
| 地上的文件堆 | 打開近景 DETAIL-009（整理桌，謎題 3） |
| 軟木板 | 謎題 3 完成後開放：近景 DETAIL-010（謎題 4） |
| 書桌 | 筆記本（含分類規則的另一半；結尾翻到最後一頁） |
| 達克 | 靠在門邊（只在答錯時說話） |

**謎題 3　整理文件（錯一次亮一格）**
- 四份文件 📄 A～D，四個資料夾（依年代分）。點文件 → 點資料夾。
- 規則（牆上一半＋筆記本一半）：
  - 牆上：「依年代歸檔，每十年一個資料夾。」
  - 筆記本：「所有年份先換成西元再分。」
- 關卡設計重點：四份文件用**不同的紀年方式**（建議：西元、民國、明治／大正、干支或皇紀等），玩家要換算後才能分對。
- 📄 A～D 內容：⚠ 待討論（建議是看起來彼此無關的普通歷史資料：公文、剪報、帳簿、照片背面說明）。
- 換算對照表放在書架上（可點開），降低難度。

**謎題 4　讀懂文件（錯一次亮一格）**
- 軟木板上釘著 📄 E、F 和整理好的 A～D。
- 步驟 1：選出「指向同一件事」的三份文件（點選三份）。
- 步驟 2：回答「我之前在查什麼？」四選一（沿用 N01 最終推理的兩步介面）。
  - 正解方向：「不同年代、不同名字，卻用同樣手法經手同類物品的一群人」
  - ⚠ 選項文字不能出現組織名稱。
- 📄 E、F 內容：⚠ 待討論（關鍵是「名字不同、手法相同」的共同點要看得出來）。

### 結尾
- 謎題 4 完成 → 筆記本最後一頁（「是他。」＋被塗掉的名字，與 N01 借閱卡同筆跡）→ 達克離開 → 完。

## 六、文件與密碼內容（Claude 暫編，待製作人看過再調整）

設計原則：所有文件都是「看起來普通的歷史資料」。共同點是——**不同年代、不同團體名稱，都以「送修」為名收走古物，都存放在「第七倉庫」，東西都沒有回來。** 不出現組織名稱、不出現符號。

### 謎題 1　論文年份
- 論文草稿封面：「1907—1936 年間臺灣古物流通紀錄研究」
- 便條：「密碼：論文的第一個年份。別再忘了。」
- 桌曆干擾：圈了 3 月 12 日、10 月 25 日
- **答案：1907**

### 謎題 2　家門
- 筆記本第一頁：「家門：門牌，接上我第一次進研究室的那天（月日）。」
- 門牌：37
- 研究室出入證：首次登記 2023.09.18
- **答案：370918**

### 謎題 3　四份文件（四個資料夾：1900s／1910s／1920s／1930s）
| 文件 | 紙張 | 內容（重點） | 紀年 | 西元 | 資料夾 |
|---|---|---|---|---|---|
| 📄 A | 舊公文 DOC-016 | 臺北廳「古器物移出許可」。申請者：東洋古美術研究會。物品：青銅古鏡一面。事由：送修。寄存：大稻埕第七倉庫。 | 明治四十年 | 1907 | 1900s |
| 📄 B | 舊帳簿 DOC-018 | 商行「代管古物」入庫紀錄。委託人：臺灣舊慣器物調查會。物品：玉質印材一方。存放：第七倉。出庫欄空白。 | 大正五年 | 1916 | 1910s |
| 📄 C | 舊剪報 DOC-017 | 上海報紙短訊：蘇州古寺石經「送修」後下落不明。承修者：江南金石研究社。暫存滬上第七號貨棧。 | 民國十二年 | 1923 | 1920s |
| 📄 D | 舊照片背面 DOC-019 | 「攝於第七倉庫前・修復委託品交接紀念」，幾個看不清的簽名。 | 1936 年 5 月 | 1936 | 1930s |
- 換算對照表（DOC-022，書架上）：明治＋1867、大正＋1911、昭和＋1925、民國＋1911
- 陷阱：大正五年和民國五年換算結果一樣，玩家容易以為「不用換算」；明治差最多，最容易放錯。

### 謎題 4　讀懂文件（兩題，各四選一）
- 📄 E（舊信紙 DOC-020，無署名、無日期）：「各地分會更名一事，已照辦。物品仍照舊例，以修復為名收存，存放處一律稱『第七』。」
- 📄 F（主角筆記，DOC-011）：
  「東洋古美術研究會（1907）／臺灣舊慣器物調查會（1916）／江南金石研究社（1923）／？（1936）
  名字都不一樣。都說『送修』。都放在『第七』。東西都沒有回來。」
- 第一題：這些文件的共同點是？
  1. 都發生在臺北
  2. **都以送修為名收走古物，存放在「第七」，沒有歸還** ✓
  3. 都是同一個人簽名
  4. 都是政府公文
- 第二題：我之前在查什麼？
  1. 日治時期的文物修復制度
  2. **一群不斷改名、以送修為名收走古物的人** ✓
  3. 臺灣古物走私到上海的路線
  4. 第七倉庫的建築歷史
- 答錯任一題亮一格（與謎題 3 共用三格）。
