# N01 劇情改版 v3（草稿，待劇本負責人確認）

## 這一節的定位
- 主軸是「逃離」：教授要主角在保安巡到之前離開舊文獻館。
- 主角只知道自己少了 21:00–21:07 的七分鐘，本節不解釋發生了什麼。
- 艾琳提前簽清場表、錄音裡的爭吵、終端快七分鐘，用拼接手法讓玩家以為「這就是那七分鐘」。結尾主角發現它們都是別人自己的事，跟他無關。
- 真相（後面章節才揭露，本節只埋伏筆）：主角是姆組織某位成員的孩子，查到一位長老的真實身分後，回來這裡拿關鍵資料，被那位長老察覺，因此失憶。

## 新增／修改的台詞（程式已放入，標記為草稿）

### 開場電話（D01 選項之後）
- 因杜阿森（電話）：聽好。夜間保安很快就會開始巡樓，在他巡到你那裡之前離開。
- 主角：被看到又怎樣？我又不是小偷。
- 因杜阿森（電話）：別讓保安看到你。他看到了什麼，就會有人知道。
- 主角：……誰會知道？
- 因杜阿森（電話）：先出來。出來以後再說。
- （廣播、通道門鎖著）
- 主角：我記得九點整走進這間閱覽室。再來……就是現在。
- 主角：中間少了七分鐘。
- 任務：在保安巡到之前離開舊文獻館

### 保安警戒（答錯一次＋1，滿 3 次失敗）
算答錯的地方：配電箱過載、終端校時錯、打開錯的 M 類卷宗、錄音排序錯、最終推理錯、清查人數錯。
1. 保安（門外）：……嗯？誰在那裡？
2. 保安（門外）：有人在裡面嗎？這個時間不能進來。
3. 保安（門外）：你怎麼會在這裡？站好，我要通知警察。→ 失敗畫面「被保安發現了」
- 失敗後進度清空。重新挑戰會略過序幕和開場電話，直接開始。

### 伏筆：保安是眼線（教授不知道）
- 教授開場那句「他看到了什麼，就會有人知道」。
- 找到卷宗後回到走廊，隔著門聽到保安講電話：「今晚一切正常。……是，我會照之前講的報告。」主角：「……照之前講的？」
- 結尾對講機那段之後，主角：「（他沒看見我的臉。趁現在走。）」
- 保安的人設不變：普通人、照職責巡邏。

### 伏筆：長老的名字（A 借閱卡＋C 書裡的信）
長老姓氏先用「顧」（暫定，程式常數 `ELDER_SURNAME`，改一個地方全部跟著換）。
- **A 借閱卡**：在卷宗 1204-M-03 封底。最後一列借閱人被墨水塗掉，只剩「顧」，旁邊是主角筆跡「是他。」
  - 主角：借閱人的名字被墨水塗掉了，只剩一個「顧」。
  - 主角：旁邊那兩個字……是我的筆跡。
  - （若已讀過信）主角：閱覽室那封信的署名，也是「顧」。
- **C 書裡的信**（隱藏，不進提示）：閱覽室左邊書架的舊館藏目錄裡夾著一封信。
  > 館長：第三櫃的捐贈文獻，照舊不對外開放。借閱紀錄由你親自保管，不必經過館務組。若有人問起，就說那批資料早已銷毀。　顧（後面的字跡潦草，難以辨認）

### 結尾（離館後、教授出現前）
- 主角：艾琳先簽了清場表。錄音裡是別人在吵架。終端的時間快了七分鐘。
- 主角：每一件事都對得上那七分鐘。
- 主角：可是沒有一件，是我做的。
