# N01 劇情改版 v3（草稿，待劇本負責人確認）

## 這一節的定位
- 主軸是「逃離」：教授要主角在保安巡到之前離開舊文獻館。
- 主角只知道自己少了 21:00–21:07 的七分鐘，本節不解釋發生了什麼。
- 艾琳提前簽清場表、錄音裡的爭吵、終端快七分鐘，用拼接手法讓玩家以為「這就是那七分鐘」。結尾主角發現它們都是別人自己的事，跟他無關。
- 真相（後面章節才揭露，本節只埋伏筆）：主角是姆組織某位成員的孩子，查到一位長老的真實身分後，回來這裡拿關鍵資料，被那位長老察覺，因此失憶。

### 保安警戒（答錯一次＋1，滿 3 次失敗）
算答錯的地方：配電箱過載、終端校時錯、打開錯的 M 類卷宗、錄音排序錯、最終推理錯、清查人數錯。
1. 保安（門外）：……嗯？誰在那裡？
2. 保安（門外）：有人在裡面嗎？這個時間不能進來。
3. 保安（門外）：你怎麼會在這裡？站好，我要通知警察。→ 失敗畫面「被保安發現了」
- 失敗後進度清空。重新挑戰會略過序幕和開場電話，直接開始。

### 伏筆：保安是眼線（教授不知道）
- 教授開場那句「他看到了什麼，就會有人知道」。
- 找到卷宗後回到走廊，隔著門聽到保安講電話：「今晚一切正常。……是，我會照之前講的報告。」主角：「……照之前講的？」
- 結尾對講機那段之後，主角：「（他沒看見我的臉。趁現在走。）」
- 保安的人設不變：普通人、照職責巡邏。

### 伏筆：長老的名字（A 借閱卡＋C 書裡的信）
長老名字一律模糊成馬賽克，看不出任何字（主角失憶、閱讀能力下降），身分之後再設定。
- **A 借閱卡**：在卷宗 1204-M-03 封底。最後一列借閱人的名字是一團模糊，旁邊是主角筆跡「是他。」
  - 主角：最後一個借閱人的名字……我看不清楚。字明明就在那裡。
  - 主角：旁邊那兩個字……是我的筆跡。
  - （若已讀過信）主角：這個簽名的筆畫，跟閱覽室那封信上的很像。
- **C 書裡的信**（隱藏，不進提示）：閱覽室左邊書架的舊館藏目錄裡夾著一封信。
  > 館長：第三櫃的捐贈文獻，照舊不對外開放。借閱紀錄由你親自保管，不必經過館務組。若有人問起，就說那批資料早已銷毀。　（署名模糊，看不出字）

## v4：降低難度、教授的電話引導（草稿）
每個步驟第一次到對的房間，教授會先說方向；第一次答錯（或卷宗櫃連開錯兩個抽屜）時，教授會再給具體一點的提示。這些都不算在 2 次免費提示裡。

| 步驟 | 進房時的引導 | 第一次答錯時的提示 |
|---|---|---|
| 配電箱 | 教授：先讓燈亮起來，牆上有備用配電箱／主角：左邊牆上，紅燈在閃／教授：線路老、一次開太多會跳脫，先看每一路吃多少電 | 教授：門內側的負載表被弄髒那格，看電錶記得的跳脫總量／教授：門禁一定要開，算哪一路可以先關 |
| 訪客卡 | 教授：讀卡器亮了嗎？／主角：亮了／教授：用桌上的臨時訪客卡 | — |
| 保安終端 | 主角：走廊，有鐘和保安終端／教授：門要靠終端開，但我不信任它的時間／教授：找一件被兩台機器同時記下的事，差多少就錯多少 | 教授：測試表和值班登記板，T-07 各記了一次／教授：終端時間減真正時間，差幾分就往回調幾分 |

## v5：結尾不再出現教授（製作人決定）
- 教授整節只在電話裡出現。離館後的館外場景**不再有教授本人、立繪與台詞**（原本「找到你想找的東西了嗎？」「不知道自己正在找什麼，比誤以為自己已經找到答案要好。」兩句已刪）。
- 結尾順序：離館時間 → 三句反轉 →「我連自己想找什麼……都不知道。」（原本是回答教授，改成自言自語）→ 紙條正反面與申請單自動打開 → 二樓西側閱覽室窗燈熄掉 → 主角最後一句 → 系統字幕「雨聲漸漸停了」→ 黑場 → 結算卡。
- 結算卡預告：「雨停了。街燈下，有人等了一段時間。」＋「下一節「留下來的人」」。第二節開場是雨停後的舊館外。
- 第二節教授第一次露面，台詞「你在電話裡說，出來以後再說。」與第一節開場電話（「先出來。出來以後再說。」）一致。
